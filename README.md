# EmbedCalc RPM 仓库

## 快速安装

```bash
# 添加仓库
sudo dnf config-manager --add-repo https://spp901780.github.io/embedCalc/embedcalc.repo

# 安装 EmbedCalc
sudo dnf install embedcalc
```

## 更新

```bash
sudo dnf update embedcalc
```

## 支持的发行版

- Fedora 38+
- RHEL 9+
- CentOS Stream 9+
